# 0003. 시각은 기기 시계를 그대로 쓴다
- **날짜:** 2026-11-01
- **상황:** "기존 전자시계보다 정확한 시계"가 목표다. 화면이 시각을 어디서 가져올지 정해야 했다.
- **선택지:**
  1. 기기 시계를 그대로 씀 (안드로이드가 와이파이로 시간 서버에 맞춰 둔 값)
  2. 페이지가 따로 시간 서버에 물어서 보정
- **결정:** 1번. 대신 초가 바뀌는 순간에 맞춰 화면을 다시 그려서, 표시가 실제 시각보다 늦게 넘어가지 않게 했다.
- **이유:** 안드로이드는 "자동 날짜 및 시간"이 켜져 있으면 스스로 맞춘다. 웹페이지가 쓸 수 있는 공개 시간 서버는 따로 정해진 게 없고, 응답 시간만큼 오차가 다시 생긴다. 탁상시계 용도로는 1번이면 충분하다고 판단했다. (추측: 기기 오차는 1초보다 훨씬 작을 것. 실측은 안 함)
- **나중에 바꿀 수 있는 조건:** 태블릿 화면을 UTCk 등과 나란히 놓고 봤을 때 눈에 띄게 어긋나면 2번을 검토한다.
