# 0008. 밝게 테마는 사진 속 카드 디자인으로 바꾼다
- **날짜:** 2026-11-01
- **상황:** 사용자가 위젯 카드 디자인 사진(검은 바탕에 연회색 카드, 큰 숫자, 주황 포인트)을 보내며 밝은 화면을 이렇게 하고 싶다고 했다.
- **선택지:**
  1. 밝게 테마를 카드 디자인으로 바꾸고, 검정 테마는 지금처럼 카드 없이 둔다
  2. 두 테마 모두 카드 디자인으로 바꾼다
- **결정:** 1번. 화면 구조는 하나로 두고, 카드 색·여백·글자 굵기만 테마 값으로 바꾼다. (검정 테마에서는 카드가 투명하고 여백이 0)
- **이유:** 검정 테마는 사용자가 기본으로 쓰겠다고 한 화면이라 그대로 둔다. 구조가 하나라 기능을 고칠 때 두 번 고칠 필요가 없다.
- **글꼴:** 사진 속 글꼴은 정확히 확인하지 못했다(추측: Helvetica 계열의 네오 그로테스크 글꼴). 프리텐다드의 영문·숫자는 Inter라는 비슷한 계열 글꼴을 바탕으로 만들어져 있어서, 새 글꼴을 추가하지 않고 프리텐다드를 계속 쓴다.
- **나중에 바꿀 수 있는 조건:** 검정 테마에서도 카드가 낫다고 하면 2번으로 바꾼다. (CSS의 `--card` 값만 바꾸면 된다)
