# 0006. 공개 주소는 GitHub Pages로 만든다
- **날짜:** 2026-11-01
- **상황:** Claude 미리보기(Artifact) 링크는 로그인이 필요한 비공개 링크이고, 외부 서버 접속이 막혀 날씨가 안 뜬다. 태블릿에서 매일 쓰고 다른 사람에게도 줄 수 있는 주소가 필요했다.
- **선택지:**
  1. Claude 미리보기 링크 (로그인 필요, 날씨 안 됨)
  2. GitHub Pages (무료, 저장소가 공개여야 함)
  3. Cloudflare Pages, Netlify 같은 다른 무료 호스팅 (가입이 하나 더 필요)
- **결정:** 2번. 공개 저장소 `xarvogpt/desk-clock`의 main 브랜치 루트를 그대로 게시한다. 주소: https://xarvogpt.github.io/desk-clock/
- **이유:** 이미 GitHub 계정이 있고 git도 연결돼 있다. 올리면(push) 1분 안에 반영된다. 저장소에는 비밀번호나 키 같은 숨길 값이 없어서 공개해도 문제없다.
- **나중에 바꿀 수 있는 조건:** 저장소를 비공개로 돌려야 할 이유가 생기거나, 개인 도메인(주소)을 붙이고 싶을 때 다시 검토한다.
