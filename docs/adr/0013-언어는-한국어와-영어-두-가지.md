# 0013. 언어는 한국어와 영어 두 가지, 화면 안 번역표로 처리한다
- **날짜:** 2026-11-05
- **상황:** 다른 사람도 쓸 수 있게 공개했으니 영어 사용자도 고려해야 했다. 사용자는 한국어와 영어 두 가지만 원했다.
- **선택지:**
  1. 브라우저 자동 번역에 맡김 (날짜·숫자 형식이 어색하고, 꺼 두면 그대로 한국어)
  2. 화면 파일 안에 한국어·영어 번역표를 두고 설정에서 바꿈
  3. 번역 도구(라이브러리)와 언어별 파일을 따로 둠
- **결정:** 2번. `app.html` 안의 `STR` 표에 두 언어 문구를 같이 두고, 고정 글자에는 `data-i18n` 표시를 붙여 한 번에 바꿔 끼운다. 기본값은 기기 언어(한국어면 한국어, 아니면 영어).
- **이유:** 언어가 두 개뿐이라 별도 도구를 쓰면 오히려 복잡하다. 파일 하나로 관리하던 방식(ADR 0002)을 그대로 유지할 수 있다.
- **나중에 바꿀 수 있는 조건:** 언어가 3개 이상으로 늘면 언어별 파일로 나누는 3번을 검토한다.
