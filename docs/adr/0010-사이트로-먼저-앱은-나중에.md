# 0010. 지금은 웹사이트(+홈 화면 앱)로 다듬고, 네이티브 앱은 나중에 검토한다
- **날짜:** 2026-11-01
- **상황:** 사용자가 안 쓰는 아이패드로 쓰기 시작했고, 와이파이가 꺼지면 동작하는지, 화면이 안 꺼지게 할 수 있는지 물었다. "사이트로 만들다가 나중에 앱으로 넘어가는 게 맞는 것 같다"고 했다.
- **선택지:**
  1. 지금 바로 아이패드·안드로이드 앱으로 다시 만든다
  2. 웹사이트를 계속 다듬고, 홈 화면 앱(PWA)과 오프라인 사본으로 앱에 가깝게 쓴다. 앱 전환은 나중에 한다
- **결정:** 2번.
- **이유:** 화면·기능을 자주 바꾸는 단계라 고치고 올리면 1분 안에 모든 기기에 반영되는 사이트가 빠르다. 아이패드용 정식 앱은 Mac과 Xcode가 필요하고, 남에게 배포하려면 애플 개발자 등록(연 99달러)이 필요하다(사실). 오프라인 동작과 주소창 없는 화면은 PWA로도 된다.
- **나중에 앱으로 넘어갈 조건:** 화면 꺼짐 방지, 화면이 꺼진 상태의 알람, 위젯·잠금 화면 표시처럼 웹으로는 안 되는 기능이 꼭 필요해질 때. 그때 이 화면 코드를 감싸는 방식(예: Capacitor)부터 검토한다.
