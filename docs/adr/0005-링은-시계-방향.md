# 0005. 타이머 링은 일반 시계처럼 시계 방향으로 읽는다
- **날짜:** 2026-11-01
- **상황:** 첫 시안은 Time Timer 제품처럼 숫자를 시계 반대 방향(맨 위 0, 왼쪽으로 5, 10…)으로 배치했다. 사용자가 "숫자가 반대로 써 있어서 이상하다"고 했다.
- **선택지:**
  1. 숫자는 시계 방향, 빨간 칸은 0에서 시계 방향으로 남은 분만큼 (빨간 칸 끝의 숫자 = 남은 분)
  2. 숫자는 시계 방향, 빨간 칸은 0에서 시계 반대 방향 (지금 쓰는 레토 시계 사진과 비슷하지만, 빨간 칸 끝의 숫자가 남은 분과 맞지 않음)
- **결정:** 1번.
- **이유:** 일반 시계와 같은 방향이라 익숙하고, 빨간 칸 끝 숫자만 보면 남은 시간을 바로 알 수 있다. 링을 끌 때도 "45에 놓으면 45분"으로 직관적이다.
- **나중에 바꿀 수 있는 조건:** 실제로 써 보고 줄어드는 방향이 어색하면 2번으로 바꾼다. (`app.html`의 링 그리기·끌기 부분에서 각도 부호만 바꾸면 된다)
