# 0004. 날씨는 Open-Meteo에서 받는다
- **날짜:** 2026-11-01
- **상황:** 다른 사람도 쓸 수 있어야 하므로 지역을 사용자가 고르게 했다. 날씨를 어디서 받아올지 정해야 했다.
- **선택지:**
  1. 기상청 공공데이터 (가입하고 인증키를 받아야 함. 키가 페이지에 그대로 드러남)
  2. OpenWeatherMap 등 해외 서비스 (가입과 키 필요)
  3. Open-Meteo (가입·키 없음, 개인·비상업 용도 무료)
- **결정:** 3번. 날씨는 15분마다 새로 받고, 지역 검색도 Open-Meteo의 지명 검색을 쓴다.
- **이유:** 키가 없어서 페이지를 공개해도 숨길 값이 없다. 다른 사람이 따로 가입할 필요도 없다.
- **나중에 바꿀 수 있는 조건:** 한국 날씨가 실제와 자주 다르거나, 사용자가 많아져 무료 이용 조건을 넘으면 기상청 데이터를 검토한다.
