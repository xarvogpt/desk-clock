# 0001. 기성 탁상시계 대신 태블릿에 직접 만든 화면을 띄운다
- **날짜:** 2026-11-01
- **상황:** 지금 쓰는 타이머 겸 시계(레토 LTM-C01)는 시각을 매번 직접 맞춰야 하고 초가 안 보인다. 원형 타이머, 초 표시, 날짜, 날씨를 다 갖춘 기성품을 찾기 어려웠다.
- **선택지:**
  1. 전파시계 (한국은 일본 신호를 받는 제품이 많고, 지역에 따라 수신이 불안정할 수 있음)
  2. 와이파이 시계나 스마트 디스플레이 (원형 타이머처럼 원하는 모양을 고를 수 없음)
  3. 집에 있던 갤럭시 탭 A with S펜 (비밀번호를 모르고 충전이 됐다 안 됐다 함)
  4. 새 태블릿을 사서 직접 만든 화면을 띄움
- **결정:** 4번. 테클라스트 P50T(11인치, 안드로이드 16)를 산다.
- **이유:** 와이파이로 시각이 자동으로 맞고, 화면 구성을 마음대로 정할 수 있다. 책상에 앉아 있을 때만 켜고 충전하므로 배터리 부담이 적다.
- **나중에 바꿀 수 있는 조건:** 11인치가 책상에서 너무 크게 느껴지면 8~9인치 태블릿으로 바꾼다. 화면은 웹페이지라 기기를 바꿔도 그대로 쓴다.
