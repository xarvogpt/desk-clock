# 0002. 안드로이드 앱 대신 웹페이지 한 장으로 만든다
- **날짜:** 2026-11-01
- **상황:** 태블릿에 띄울 시계 화면을 어떤 형태로 만들지 정해야 했다. 다른 사람도 쓸 수 있게 하고 싶다.
- **선택지:**
  1. 안드로이드 앱 (설치 파일을 만들어 배포)
  2. 웹페이지 한 장 (브라우저로 열고 "홈 화면에 추가")
- **결정:** 2번. 파일 하나(`index.html`)로 만든다. 설정은 각자의 브라우저에 저장된다.
- **이유:** 고칠 때 다시 설치할 필요가 없고, 태블릿·폰·PC 어디서든 같은 화면이 뜬다. 다른 사람은 주소만 받으면 바로 쓸 수 있고, 각자 지역과 표시 방식을 따로 설정한다.
- **나중에 바꿀 수 있는 조건:** 브라우저가 막는 기능(화면 꺼짐 방지가 안 됨, 화면이 꺼진 상태에서 알림 소리 등)이 꼭 필요해지면 앱으로 감싸는 방법을 검토한다.
