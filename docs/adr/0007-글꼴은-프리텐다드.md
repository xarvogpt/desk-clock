# 0007. 글꼴은 프리텐다드 하나로 쓴다
- **날짜:** 2026-11-01
- **상황:** 처음 쓴 글꼴(숫자 Azeret Mono, 글자 IBM Plex Sans KR)이 못생겼다는 피드백을 받았다. 사용자가 프리텐다드를 원했다.
- **선택지:**
  1. Google Fonts 안에서 다른 글꼴 찾기 (Claude 미리보기에서도 보임)
  2. 프리텐다드 (무료, SIL 오픈 폰트 라이선스. Google Fonts에는 없어서 jsDelivr에서 불러옴)
- **결정:** 2번. 버전을 v1.3.9로 고정한 가변 글꼴(필요한 글자만 내려받는 방식)을 쓴다. 숫자는 폭을 같게(tnum) 맞춘다.
- **이유:** 사용자가 고른 글꼴이고, 한글과 숫자가 모두 깔끔하다. 무료이고 상업적으로 써도 된다. 실제로 쓰는 곳은 공개 주소라서 미리보기에서 안 보이는 건 문제가 아니다.
- **나중에 바꿀 수 있는 조건:** jsDelivr가 느리거나 막히는 환경이 생기면, 글꼴 파일을 저장소에 직접 넣어 GitHub Pages에서 같이 내려받게 한다.
