# 0009. 전체 화면 유지는 "홈 화면 앱 설치"로 해결한다
- **날짜:** 2026-11-01
- **상황:** 사이트를 전체 화면으로 띄워 두면 가끔 전체 화면이 풀린다. 시계는 전체 화면으로 볼 때 예뻐야 한다.
- **선택지:**
  1. 브라우저 전체 화면 그대로 (풀리면 버튼을 다시 눌러야 함)
  2. 풀리면 다음 탭에서 자동으로 다시 전체 화면 (브라우저 규칙상 탭 없이는 불가)
  3. 웹 앱 설치(PWA): 앱 정보 파일에 "전체 화면으로 열기"를 적어 두고 홈 화면 아이콘으로 실행
  4. 안드로이드 앱으로 감싸기, 또는 키오스크(화면 고정) 앱 사용
- **결정:** 3번을 기본으로 하고, 브라우저로 쓸 때를 대비해 2번도 함께 넣는다.
- **이유:** 3번은 브라우저 탭이 아니라 앱 창으로 열리므로 주소창이 아예 없고, 위·아래를 쓸어 시스템 바가 잠깐 나와도 다시 숨는다(안드로이드 기본 동작). 따로 앱을 만들거나 배포할 필요가 없다. 서비스 워커는 아무것도 저장하지 않게 해서, 고친 내용이 바로 반영된다.
- **나중에 바꿀 수 있는 조건:** 태블릿에서 설치 앱도 자꾸 꺼지거나 화면이 꺼지면, 4번(키오스크 앱이나 안드로이드 앱으로 감싸기)을 검토한다.
