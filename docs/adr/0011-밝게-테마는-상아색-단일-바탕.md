# 0011. 밝게 테마는 카드 없이 상아색 단일 바탕으로 한다 (0008번을 대체함)
- **날짜:** 2026-11-03
- **상황:** 0008번에서 밝게 테마를 "검은 바탕 + 연회색 카드"로 했는데, 실제로 보니 카드 사이 검은 틈 때문에 화면이 칸칸이 나뉘어 보여 이상하다는 피드백을 받았다. 사용자는 배경 전체가 약간 상아색이길 원했다.
- **선택지:**
  1. 카드 디자인 유지, 바탕만 상아색으로 (카드와 바탕의 경계는 남음)
  2. 카드를 없애고 화면 전체를 상아색 한 장으로 (검정 테마와 같은 배치)
- **결정:** 2번. 바탕 #f3efe4, 글자 #1b1a17, 포인트 #bf5a2c.
- **이유:** 사용자가 원한 것이 "전체가 상아색"이고, 칸 나눔 자체가 거슬린다고 했다. 검정 테마와 배치가 같아져서 두 테마를 오갈 때도 위치가 변하지 않는다.
- **나중에 바꿀 수 있는 조건:** 다시 카드 느낌이 필요하면 `--card`, `--card-pad`, `--app-gap` 값만 바꾸면 된다.
